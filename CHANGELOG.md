# Changelog

## 1.0.0 — 2026-10-22

Initial playable release: the full Aster Beacon campaign, six regions, 36 original companions, four wardens, nine traveler challenges, catching, ten elements, evolving parties, sanctuary storage, field journal, shops, healing, fast travel, local saves with recovery, generated artwork and music, keyboard/mouse input, and an open postgame.

Includes a distributable LÖVE archive, automated pure-Lua tests, real-engine screenshot smoke tests, and GitHub Actions validation.
